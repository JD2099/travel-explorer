# Travel Explorer
Travel Explorer is a simple web application that helps users discover countries and explore travel destinations. It displays useful information about countries and provides weather forecasts for their capital cities.

## Features
- Search for a country and view facts from REST Countries.
- View current weather for the capital city using Open-Meteo.
- Save favorite destinations and recent searches with `localStorage`.
- Discover a random country.
- Responsive layout, CSS animations, loading/error messages, accessibility basics, and SEO metadata.

## APIs
1. REST Countries: `https://restcountries.com/`
2. Open-Meteo Geocoding and Weather: `https://open-meteo.com/`


## Technologies
- HTML5
- CSS3
- JavaScript (ES modules)
- Fetch API
- JSON
- Browser Local Storage

## Learning Outcomes
This project demonstrates the use of JavaScript modules, asynchronous API requests, JSON data processing, DOM manipulation, event handling, CSS styling, and local storage to create an interactive web application.
